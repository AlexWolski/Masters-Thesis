\chapter{Data~Availability}
\label{chap:data_availability}

The implementation of CSG-CRN is available in the GitHub repository at \href{https://github.com/AlexWolski/CSG-CRN}{\nolinkurl{github.com/AlexWolski/CSG-CRN}}. All datasets and trained model weights used in the experiments are available in the Hugging Face repository at \href{https://huggingface.co/datasets/AlexWolski/CSGCRN-SDF-Dataset}{\nolinkurl{huggingface.co/datasets/AlexWolski/CSGCRN-SDF-Dataset}}.
