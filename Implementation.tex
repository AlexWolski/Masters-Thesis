\section{Dataset~Processing}
\label{sec:dataset_processing}

We use the ShapeNetCore v2 dataset~\cite{Chang2015} for training and performance testing. This is a collection of 51,641 3D meshes sorted into 54 categories. ShapeNet is commonly used by related work and makes for easy performance comparison.

The dataset needs to be preprocessed before it can be used in CSG-CRN. A signed distance value can only be computed for watertight manifolds where an interior and exterior volume are clearly defined.. We apply the Manifold remeshing algorithm provided by Point Cloud Utils~\cite{Williams2022} to seal any holes and remove loose geometry that is present in the dataset. Then we normalize the mesh by centering it on the origin and scaling it to fit a unit sphere using tools provided by Mesh to SDF~\cite{Kleineberg2024}.

Once the meshes have been cleaned, we extract three types of point samples. Samples directly on the mesh surface are required for the Chamfer Distance and Earth Movers Distance accuracy metrics. The surface samples are generated using Point Cloud Utils, which uses mesh face area weighting to ensure the points are uniformly distributed on the surface. The surface sample can then be used to generate near-surface samples following the method used by DeepSDF~\cite{Park2019}. The surface points are offset by adding 3D Gaussian noise with a standard deviation of 0.1. Lastly, samples are generated uniformly in a unit sphere. Point Cloud Utils is used compute the signed distance to the mesh for both the near-surface and uniform samples. The final dataset we produced contains 16,384 uniform samples, 16,384 near surface samples, and 30,000 surface samples.
